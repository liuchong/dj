# 支持范围

DJ 当前交付本机常驻消息枢纽、运行包和 AI 调用接口。核心要求是通知准确的已有会话，不以新建 Agent CLI 进程冒充接收。配置、源码能力和真实运行证据分别判断。

## 能力与验证范围

| 能力 | 当前交付 | 边界 |
| --- | --- | --- |
| 会话查询与直发 | 配置范围内的工具/实例/工作区目录、准确 resolve/probe、免订阅 session.send | 不扫描任意机器路径，不因名称相同替换目标，不自动启动会话 |
| IM 实时收件 | Lark / 飞书官方 WebSocket 与 HTTPS，独立 user/bot 连接 | 原生事件、账号与资源覆盖受平台授权约束；其他 IM 专项验证后置 |
| 订阅 | 默认全部获准对话、可选来源收窄、@、关键词与组合条件、固定提示词 | DJ 不推断任务归属；不把自然语言要求交给服务判断 |
| 触发过滤 | 人员、字面字符和组合黑名单 | 只拦自动触发，不删除消息或改变查询可见性 |
| 上下文与规则 | 本地历史、引用、话题/thread、主动拉取、持久对话规则 | 不做自动摘要；原文不改写；读取不冒充实时事件 |
| 回复与处理状态 | 固定来源和身份的 message.reply、收到确认、处理中表情清理 | 普通输出不自动外发；平台接受不等于人已读或任务已完成 |
| AI 主动消费 | subscription.pull/ack；Codex/Cursor 可选回调配置 | 领取确认不等于任务完成，配置生成不等于客户端已启用 |
| 公共调用面 | CLI、本地 API、stdio MCP、GEPO、完整 Skill 安装与配置指引 | 共用授权与幂等；不自动安装客户端配置或放宽信任 |
| 可选会话创建 | 已有实例中的显式空会话创建接口 | 受原生能力、工作区和独立授权约束；不作为核心通知的前置 |

工具逐项证据见[当前状态](status.md)；原生方式见[Agent 适配](adapters/agent-tools.md)。

## 保持的约束

- 不调用模型或语义路由；调用方明确选择目标、来源与规则。
- 不用 argv prompt、新 Agent 进程、云端控制、轮询或重放冒充已有会话和真实实时收件。
- 本机权限、撤销、去重、submitting 提交点、unknown 屏障和安全排空不因交付优先级裁掉。
- 原生支持缺失时返回 unsupported/partial/unknown，不把安装许可、历史存在或一次握手当作完整支持。
