# 历史资料

此处保留早期研究、施工资料和分批验证记录，供定位设计由来与既有失败。内容按当时事实保存，不能作为当前支持声明、开发顺序或执行授权。

当前使用看[安装指南](../delivery.md)，当前实现和边界看[项目状态](../status.md)与[产品规格](../index.md#产品规格)，开发看[开发指南](../guides/development.md)。历史材料中已被替代的 CLI 启动、兼容层、测试先行和全矩阵验收提议不再适用。

| 资料 | 内容 |
| --- | --- |
| [状态记录](status-notes.md) | 构建、诊断、失败与修复后结果 |
| [历史检查清单](implementation-checklist.md) | 已结束阶段的原始施工和验收勾选 |
| [研究](research.md)、[设计审阅](design-review.md) | 早期协议研究和设计问题 |
| [施工计划](construction-plan.md)、[施工契约](construction-contracts.md) | 分阶段实现设计与增量记录 |
| [依赖准备](readiness.md) | 固定工具链的早期准备和重建配方 |
| [操作字段表](operation-catalog.md) | 早期人工字段目录；现行 schema 由代码生成 |
| [测试计划](test-plan.md)、[用例卡](case-cards.md)、[真实验收准备](real-preflight.md) | 用例设计、控制器资料与当时装配状态 |
| [原验收场景矩阵](acceptance-matrix.md) | 早期需求编号与场景，含现行已排除的进程托管分支 |
| [Goal 文案](goal.md) | 已结束阶段的目标正文，不表示有运行中的 Goal |
