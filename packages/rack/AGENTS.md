# Rack

Standalone Eliscript package. Source, documentation, examples, diagnostics and
package metadata describe only this package's own public contract. Do not add
reference-project names, source locations, branded symbols or dependency aliases.
Do not depend on an application that consumes this package.

Implement the complete functional slice before integration acceptance; add
critical protective unit tests after integration passes. Generated modules are
build products. Resource ownership, asynchronous teardown, failed initialization,
dependency replacement and scope boundaries are mandatory behavior, not optional
test conveniences. Never report behavioral equivalence from a few happy paths.
